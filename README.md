# Suaminel Limited - Corporate Website

A premium, high-fidelity corporate website for **Suaminel Limited**, a multi-sector company based in Abuja, Nigeria. The platform showcases the company's expertise in Security Services, Civil Engineering, ICT Consultancy, and more.

## 🌟 Key Features

- **Interactive Hero Slider**: 3-slide cinematic experience with centralized call-to-actions, featuring high-fidelity imagery of Nigerian professionals and Abuja's landscape.
- **Premium Design System**: A sleek Gold (#C5A059) and Charcoal (#1A1A1A) visual identity optimized for corporate prestige.
- **Full Service Catalog**: Detailed exploration of Security (Manned Guarding, Surveillance), Construction, Solar Energy, and ICT sectors.
- **Responsive Navigation**: A glassmorphic sticky navbar that adapts to mobile devices with a custom slide-in menu.
- **Integrated Map View**: Interactive Google Maps location for the Abuja headquarters at Gimbiya Street, Area 10.
- **Modern Animations**: Smooth page transitions and scroll-reveal effects powered by Framer Motion.
- **Diversity Focused**: High-quality imagery representing the local Nigerian context and professional excellence.

## 🛠️ Technology Stack

- **Core**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS (Custom Design System)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router v7](https://reactrouter.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd suaminel
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
